## Objective

Establish an integrated documentation generation subproject for `mkdocs-kit`, enabling simultaneous generation of static HTML sites, WeasyPrint PDF manuals, and UNIX troff man pages from a single Markdown source tree, with automated deployment via GitHub Actions.

---

## Deliverables & Results

1. **Integrated Documentation Subproject (`doc/`)**:
   - Structured MkDocs documentation tree with Material theme and offline-capable link resolution (`use_directory_urls: false`).
   - Comprehensive user guides, capabilities analysis, and diagram authoring guides.
2. **Test Project Showcase (`test_project/`)**:
   - Standalone test project showcasing all 10 diagram renderers (PlantUML, WireViz, RackDiag, PacketDiag, ByteField, BlockDiag, NwDiag, CSV tables, Plotly.js charts, and D3.js).
3. **Automated CI/CD Workflows**:
   - `.github/workflows/deploy-docs.yml`: Automated GitHub Pages deployment pipeline.
   - `.github/workflows/build.yml`: Automated package build and test matrix.
4. **PDF Engine Aspect Ratio & Page Break Hardening**:
   - Proportional SVG diagram scaling (`max-height: 22cm !important; object-fit: contain !important;`) preventing diagram clipping across printed page breaks.
