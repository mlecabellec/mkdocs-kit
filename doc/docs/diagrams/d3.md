# 🎨 D3.js Diagram Showcase

Demonstrates D3 data-driven component rendering for HTML and static vector SVG graphics for PDF documents.

```d3
data:
  - label: "API Gateway"
    value: 92
  - label: "Auth Service"
    value: 45
  - label: "Database Primary"
    value: 78
  - label: "Cache Worker"
    value: 34

  title: "Microservice Resource Demand (%)"

  width: 650

```
