# 📈 Plotly Chart Showcase

Demonstrates Plotly.js chart rendering for HTML and build-time SVG pre-rendering for PDF documents.

```plotly
data:
  - x: ["2023", "2024", "2025", "2026"]
    y: [450, 780, 1250, 2100]
    type: "bar"
    marker: { color: "#2ecc71" }
layout:
  title: "Platform Active Subscriptions"
  width: 650
  height: 380
```
