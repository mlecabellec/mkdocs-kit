## 1. Executive Summary

`mkdocs-kit` is a wrapped, highly integrated documentation generation environment compiled into a standalone, single-binary distribution. It enables technical authors and automated CI/CD pipelines to build multi-format publication suites simultaneously from a single Markdown source tree:
- Offline-capable HTML5 static documentation website powered by Material for MkDocs.
- Publication-quality styled A4 PDF manuals compiled via WeasyPrint with automatic table of contents, running headers/footers, and intra-document anchor resolution.
- Native UNIX troff Man Pages (`man1` through `man8`).
- Microsoft Word (`.docx`) deliverables with diagram rasterization.
- Atlassian Confluence space export bundles (`.zip`).

Version `0.1.0` marks the initial formal release, establishing the standalone PyInstaller executable, multi-distribution native packages (`.deb`, `.rpm`, `.pkg.tar.zst`), 10 diagram and visualization rendering engines, comprehensive diagnostic reporting, and cross-project integration capabilities.

## 5. Technical Facts, Discrepancies, Warnings & Limitations

1. **Host Python Independence**:
   - `mkdocs-kit` standalone executable is compiled with PyInstaller, embedding a Python 3.13 runtime, WeasyPrint, and all core libraries. It executes on host systems without Python or pip installed.
2. **Directory URLs Requirement (`use_directory_urls: false`)**:
   - To ensure that generated HTML files can be opened directly from local disk (`file://.../page.html`) without a running HTTP server, `use_directory_urls: false` must remain enabled in `mkdocs.yml`.
3. **Headless Execution Environment**:
   - Diagram rendering engines utilizing Java (such as PlantUML) require headless graphics configuration. In non-graphical CI runners or SSH sessions where `DISPLAY` might be set without an X11 server, set `JAVA_TOOL_OPTIONS="-Djava.awt.headless=true"` or unset `DISPLAY`.
4. **Setuptools `pkg_resources` Deprecation Warning**:
   - The upstream `blockdiag` and `nwdiag` libraries currently call `pkg_resources`. In Python 3.12+, this produces a deprecation notice from Setuptools. Packaging scripts pin `setuptools<82.0.0` to preserve full compatibility until upstream migrates to `importlib.metadata`.
5. **Standalone Executable Footprint**:
   - The frozen standalone executable (`dist/mkdocs-kit`) has a binary size of approximately **120 MB**, attributable to bundling the PyInstaller bootloader, shared native C libraries (Cairo, Pango, GdkPixbuf), WeasyPrint assets, and Java runtime resources.
6. **PDF Engine Upstream Anchors**:
   - When compiling external documentation containing unresolved relative links pointing outside the documentation root (such as root repository `CONTRIBUTING.md`), WeasyPrint logs an anchor warning; the compiler handles these gracefully by retaining standard text styling.
